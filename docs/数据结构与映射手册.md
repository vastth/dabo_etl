### 1.2 M_PRODUCT（商品主表）

```
表名: M_PRODUCT

```

|--------|--------|------|------|
| ID | 主键 | NUMBER | 商品唯一标识 |
| NAME | 商品编码 | VARCHAR2(80) | 款号，如 HFM03705864-4 |
| VALUE | 商品名称 | VARCHAR2(200) | 品名，如 气泡方糖项链 |
| PRODUCTNO | 货号 | VARCHAR2(80) | 同NAME |
| M_DIM1_ID | 品牌ID | NUMBER | 关联M_DIM，品牌维度 |
| M_DIM2_ID | 年份ID | NUMBER | 关联M_DIM，年份维度 |
| M_DIM3_ID | 季节ID | NUMBER | 关联M_DIM，季节维度 |
| **M_DIM4_ID** | **类别ID** | NUMBER | ⭐关联M_DIM，类别(项链/耳环等) |
| **M_DIM5_ID** | **性质ID** | NUMBER | ⭐关联M_DIM，性质(在售/新品/绝版) |
| M_DIM6_ID | 系列ID | NUMBER | 关联M_DIM，系列维度 |
| PRICELIST | 吊牌价 | NUMBER | 标准零售价 |
| PRICECOST | 成本价 | NUMBER | 采购成本 |
| IS_FIXEDASSETS | 是否主销品 | CHAR(1) | Y/N |
| IS_PKGMATERIAL | 是否包材 | CHAR(1) | Y/N |
| ISACTIVE | 是否有效 | CHAR(1) | Y=有效, N=无效 |

### 1.8 表关联关系

```sql
-- 核心关联SQL
FROM M_RETAILITEM ri
LEFT JOIN M_RETAIL r ON ri.M_RETAIL_ID = r.ID
LEFT JOIN M_PRODUCT p ON ri.M_PRODUCT_ID = p.ID
LEFT JOIN M_DIM d4 ON p.M_DIM4_ID = d4.ID        -- 类别
LEFT JOIN M_DIM d5 ON p.M_DIM5_ID = d5.ID        -- 性质
LEFT JOIN M_DIM d6 ON p.M_DIM6_ID = d6.ID        -- 系列
LEFT JOIN C_STORE s ON r.C_STORE_ID = s.ID
WHERE r.ISACTIVE = 'Y' AND r.STATUS = 2
```

### 2.4 仓库编码规则

| 编码前缀 | 类型 | 示例 |
|----------|------|------|
| 001 | 中山总仓 | 001=中山总仓（电商主仓） |
| 00X | 功能仓 | 002=旧款仓, 003=返修仓, 004=中转仓 |
| RT*** | 线下门店 | RT001=广州K11, RT002=北京三里屯 |
| DS*** | 电商虚拟店 | DS001=天猫, DS009=抖音 |

**仓库筛选SQL：**
```sql
-- 中山总仓
WHERE s.CODE = '001'

-- 云仓（48家参与云仓的门店）
WHERE s.IS_ALLO2OSTORAGE = 'Y'

-- 总仓+云仓（电商可售库存）
WHERE (s.CODE = '001' OR s.IS_ALLO2OSTORAGE = 'Y')

-- 线下门店
WHERE s.CODE LIKE 'RT%'

-- 电商虚拟店
WHERE s.CODE LIKE 'DS%'
```

### 2.5 日期格式

伯俊ERP日期字段使用 **NUMBER(8)** 类型，格式为 **YYYYMMDD**：

```sql
-- 示例值
BILLDATE = 20260113  -- 2026年1月13日

-- 日期转换
TO_NUMBER(TO_CHAR(SYSDATE, 'YYYYMMDD'))  -- 当天
TO_NUMBER(TO_CHAR(SYSDATE-30, 'YYYYMMDD'))  -- 30天前

-- 月份筛选
WHERE BILLDATE >= 20260101 AND BILLDATE <= 20260131
```

### 3.7 ads_inventory_health（库存健康度）

这张表不从Oracle直接抽，而是在MySQL内基于dws层计算：

```
数据来源：
- 库存数据 ← dws_inventory_daily
- 销售数据 ← dws_sales_daily
- 达播销量 ← ads_dabo_daily_sales
- 商品信息 ← dim_product
- SKU信息 ← dim_sku
- 仓库信息 ← dim_store

计算内容：
- 周转天数 = 库存 / (30天销量 / 30)
- 库存状态（滞销/缺货/正常/过高）
- ABC分级（按销售额累计占比）
- 建议补货 = (90-周转天数)*日均销量 - 退货 - 采购欠数
- 自然销量 = 全量销量 - 达播销量（用于自然销售加速度与趋势判断）
```
