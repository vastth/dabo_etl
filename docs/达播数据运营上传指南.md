# 达播CSV上传指南（运营）

## 1. 文件命名规则（必须）
- 格式：dabo_YYYYMMDD.csv
- 示例：dabo_20260203.csv
- 说明：YYYYMMDD为导出日期

## 2. 必须字段（不可缺少，但可以包含其他无用多余字段）
- 主订单编号
- 子订单编号
- 商家编码
- 商品数量
- 订单状态
- 发货时间
- 商家收入金额

## 3. 数据要求
- 保持导出的数据格式不需要手动更改

## 4. 上传目录
- 例行更新：\\192.168.0.151\hefang总部\14-数据中台\达播数据同步\例行
- 紧急更新：\\192.168.0.151\hefang总部\14-数据中台\达播数据同步\紧急

## 5. 例行更新 vs 紧急更新
- **例行更新**：每周固定时间批量导出，放入“例行”目录即可。
- **紧急更新**：达播期间每日更新，放入“紧急”目录可优先处理。
- **注意**：两类目录都会被监听，规则一致（文件命名、字段校验、去重、隔离）。

## 6. 处理结果
- 成功：文件会被自动移动到“已处理”目录并重命名为 dabo_data_时间戳.csv
- 失败：文件会被移动到“隔离”目录

## 7. 常见问题
- **文件名不符合规则**：会被直接隔离
- **重复文件**：会被识别为重复并跳过
- **必须字段缺失/格式错误**：会被隔离
